## 📝 상세 요약

📄 *1. CoTinyVLA: Chain-of-Thought Distillation for a Sub-Billion-Parameter Vision-Language-Action Model*

🔗 https://arxiv.org/abs/2607.25487

🏢 *저자*: Minhyeok Lee, Chiyoung Kim 외 6인 (소속 기관 미명시)

🔬 *메소드*: 0.9B 파라미터의 Qwen3.5-0.8B 백본 위에 세 가지 구조적 감독 기법을 결합한다. 구체적으로 ① 스텝당 16프레임의 듀얼뷰 시간적 입력, ② 35B 교사 모델로부터 에피소드 수준 Plan과 청크 수준 Think 스팬을 포함하는 계층적 Chain-of-Thought(CoT) 증류, ③ 40개의 기본 명령어를 800개 변형으로 확장하는 패러프레이즈 증강을 적용한다. 이 세 컴포넌트는 각각 서로 다른 강건성 축을 분리적으로 담당하도록 설계되었다.

💡 *컨트리뷰션*: 모델 크기를 키우지 않고도 구조적 감독만으로 3B~7B 규모의 기존 VLA 모델들을 능가함으로써, 임베디드 로봇 환경의 메모리 제약을 만족하면서도 높은 성능을 달성할 수 있음을 증명하였다.

🧪 *실험*: LIBERO-Plus 벤치마크(7가지 perturbation 차원, 10,030개 태스크)에서 Spatial 90.8%, Object 87.3%, Goal 86.6%, Long 80.7%를 기록하며 최강 7B 베이스라인 대비 각각 +4.7, +2.8, +15.9, +3.0포인트 향상을 달성하였다. 특히 Robot Initial States에서 기존 최고 모델(39.9%)을 크게 상회하는 73.6%를 기록했으며, 추론 시 GPU 메모리는 최대 2.25 GiB에 불과하다.

⭐ **0.9B 초소형 VLA 모델이 CoT 증류와 구조적 감독만으로 7B 대형 모델 전체를 LIBERO-Plus 모든 세부 항목에서 앞질렀다.**



📄 *2. SAM3D-Guided Object-Centric Representation Alignment for Vision-Language-Action Models*

🔗 https://arxiv.org/abs/2607.25912

🏢 *저자*: Zonghe Liu, Shanyuan Jie 외 5인 (소속 기관 미명시)

🔬 *메소드*: π₀ 기반 VLA 모델에 SAM3D를 동결된 3D 교사 모델로 활용하는 객체 중심 3D 표현 정렬 프레임워크를 제안한다. 태스크 관련 객체를 인식 모델로 지역화하고 객체 마스크를 생성한 뒤, SAM3D가 추출한 밀집 객체 수준 3D 표현을 π₀의 중간 시각 특징과 정렬(align)하여 정책 네트워크가 3D 정보를 내재화하도록 훈련한다. 테스트 시점에는 깊이 센서, 포인트 클라우드, 마스크, SAM3D 등 추가 모듈이 일절 불필요하며 기존의 RGB-언어-행동 추론 파이프라인이 그대로 유지된다.

💡 *컨트리뷰션*: 훈련 중에만 3D 교사 모델을 사용하고 테스트 시에는 추가 센서나 모듈 없이 2D RGB 입력만으로 3D 공간 이해 능력을 발휘하는 최초의 객체 중심 3D 정렬 VLA 방법론을 제시하였다.

🧪 *실험*: 시뮬레이션에서 LIBERO 99.1%, CALVIN 평균 연속 완료 길이 4.11을 달성하였다. 실제 환경 실험에서도 여러 서브태스크에 걸쳐 다양한 목표 객체를 다루는 장기(long-horizon) 조작 시나리오에서 특히 두드러진 성능 향상을 확인하였다.

⭐ **훈련 시에만 SAM3D로 3D 지식을 주입하여, 테스트 시에는 일반 RGB 카메라만으로 폐색·자세 변화에 강인한 로봇 조작을 가능하게 하였다.**



📄 *3. A Causality-aware Infer-diagnose-refine Framework for Test-time Modality Adaptation in VLA Models*

🔗 https://arxiv.org/abs/2607.25516

🏢 *저자*: Haoyu Zhang, Yuwei Wu 외 7인 (소속 기관 미명시)

🔬 *메소드*: 테스트 시간에 시각 관찰의 인과적 중요도를 동적으로 추정하여 행동 예측을 개선하는 모델 불가지론적(model-agnostic) IDR(Infer-Diagnose-Refine) 프레임워크를 제안한다. 사실적(factual) 시나리오와 반사실적(counterfactual) 시나리오 각각에서 행동을 추론한 뒤, 두 결과의 차이로 시각 관찰의 인과 효과를 진단하고, 이를 게이트 잔차 융합(gated residual fusion)으로 행동 예측에 반영한다. 반사실적 시나리오 생성에는 제로 패딩 개입을, 인과 효과 정량화에는 노름(norm) 기반 측도를 사용하며 추가 학습이 불필요하다.

💡 *컨트리뷰션*: 추가 학습 없이 기존 VLA 아키텍처에 플러그인 방식으로 적용 가능한 테스트 타임 시각 중요도 동적 조정 기법을 최초로 제안하였다.

🧪 *실험*: 복수의 시뮬레이션 벤치마크 및 실제 로봇 태스크에서 여러 VLA 백본(π₀ 등)에 적용 시 전반적인 성능 향상을 확인하였다. 논문에 구체적 수치가 다수 보고되었으며, 원거리 이동과 근거리 정밀 조작이 혼재하는 태스크에서 기존 고정 모달리티 융합 방식 대비 일관된 개선을 달성하였다.

⭐ **반사실적 추론으로 시각 정보의 인과 효과를 실시간 진단하여 학습 없이도 다양한 VLA 모델의 행동 예측 품질을 향상시키는 범용 테스트 타임 프레임워크를 제시하였다.**



📄 *4. INTACT: Isomorphic Intent-to-Action Learning for Search-Free World Models*

🔗 https://arxiv.org/abs/2607.26056

🏢 *저자*: Junhan Sun, Hao Zhao, Guofeng Zhang (소속 기관 미명시)

🔬 *메소드*: 행동 레이블이 있는 보상 없는 궤적으로부터 의도(intent)-행동(action) 인터페이스를 종단간 학습하는 JEPA 기반 구조 INTACT를 제안한다. 각 전이(transition)에서 물리적 의도(z_{t+1}−z_t)와 배포 의도(sg(z_g)−z_t)를 동일한 4-슬롯 문법과 공유 파라미터로 동형(isomorphic)하게 처리하며, 비대칭 엔드포인트 그래디언트로 미래 목표를 앵커로 고정한다. 이를 통해 포인트와이즈 잠재 매칭이나 전역 선형 다이나믹스 없이 표현 학습과 제어를 결합하고, 조건부 평균이 서치 없는 정책으로 직접 사용된다.

💡 *컨트리뷰션*: 기존 순방향 세계 모델이 원하는 상태 변화를 역산하기 위해 값비싼 테스트 타임 서치에 의존하던 한계를 극복하여, 단일 순방향 패스만으로 행동을 직접 출력하는 서치 프리(search-free) 세계 모델 패러다임을 제시하였다.

🧪 *실험*: LeWM 공식 4개 태스크에서 1-에폭 제로-서치 모델이 각각 85.78%, 100.00%, 97.67%, 97.89% 성공률을 달성하였다. 선택적 로컬 CEM 적용 시 9,000개 대신 384개의 후보 시퀀스만으로 96.86% 매크로 성공률을 달성하여 순수 CEM 대비 16포인트 향상, 샘플링 23.44배 절감을 이루었으며, 직접 추론 지연은 2.9~5.5ms에 불과하다.

⭐ **동형 의도-행동 구조로 테스트 타임 서치를 완전히 제거하면서도, 기존 서치 기반 세계 모델 대비 동등하거나 우월한 성능을 초고속으로 달성하였다.**



📄 *5. Reinformed Dreamer: An Asymmetric World Model Efficiently Trained through Latent Guidance*

🔗 https://arxiv.org/abs/2607.26040

🏢 *저자*: Gaspard Lambrechts, Adrien Bolland, Daniel Ebi, Damien Ernst (소속 기관 미명시)

🔬 *메소드*: 기존 비대칭 모델 기반 강화학습 알고리즘인 Informed Dreamer의 특권 정보(privileged information) 표현 학습 한계를 분석하고, 잠재 공간 가이던스(latent guidance)를 활용한 새로운 비대칭 표현 학습 목적함수를 설계하여 Reinformed Dreamer를 제안한다. 훈련 시에는 추가적인 특권 상태 정보로 잠재 표현을 유도하되, 배포 시에는 이를 제거함으로써 부분 관측 및 완전 관측 환경 모두에서 더 우수한 표현을 학습한다.

💡 *컨트리뷰션*: Informed Dreamer가 갖는 특권 정보 표현의 붕괴 문제를 인과적으로 규명하고, 잠재 가이던스 기반 목적함수로 이를 해결하여 기존 비대칭 MBRL 접근법들보다 더 일관성 있는 성능 향상을 달성하였다.

🧪 *실험*: 복수의 표준 강화학습 벤치마크에서 기존 Dreamer 및 Informed Dreamer 대비 일관된 성능 향상을 확인하였다. 특히 부분 관측 환경과 정제된 상태 정보가 주어지는 완전 관측 환경 모두에서 이전 비대칭 접근법들보다 안정적으로 우수한 결과를 달성하였다.

⭐ **잠재 공간 가이던스라는 새로운 비대칭 학습 목적함수로 Dreamer 계열 세계 모델의 표현 품질을 체계적으로 개선하였다.**


📌 *금주 트렌드 요약*

이번 주 논문들은 공통적으로 **VLA/세계 모델의 효율성과 일반화**라는 두 축을 동시에 추구하고 있다. 대형 교사 모델의 지식을 소형 모델로 증류하거나(CoTinyVLA, SAM3D), 테스트 타임에 추가 학습 없이 모델을 개선하는(IDR, INTACT) 경량·무훈련 접근법이 두드러지는 트렌드를 보인다. 또한 3D 공간 이해, 인과적 모달리티 조정, 서치 프리 제어, 비대칭 표현 학습 등 **단순 스케일업을 넘어 구조적 귀납 편향을 통한 성능 향상**이 로봇 및 세계 모델 연구의 핵심 방향으로 자리 잡고 있음을 확인할 수 있다.
